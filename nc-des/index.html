Analysis

Current live site: North Carolina's Division of Employment Security

One of the first steps in fixing something is understanding what is wrong with it.

After a review of the site, I find the following core issues.

  • Too many clicks to get to relevant information
  • No clear understanding of site hierarchy
  • Poor accessibility implementation, especially in regards to color

Now that’s out, I know what’s wrong. How do I make it right?

Well, what does this site need to do? It needs to allow quick filing of an initial claim, a weekly certification, then a visual representation of claim status. There’s my core. If anything on the site doesn’t revolve around this, it should.

User Flow Diagram

The user flow diagram lists out each state of the unemployment process and how it interacts with the other pieces.

Particular note is taken with the initial claim to weekly certification transition, as those are key components to the process.

Wireframes

The wireframes start by using each step of the user flow diagram and turning them into screens.

Elements are filled in based on the flow of the site: navigation then content.

Prototype

Prototyping allows for the flushing out of major and micro interactions.

The wireframes started in Axure, so the prototype will expand on the wireframe files by adding interactions (e.g. on hover) and click through behaviors.
