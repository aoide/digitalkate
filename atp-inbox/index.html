Summary

Overview

With this update, the AuthorPro plugin to Arbortext has a single Inbox instead of two separate Inboxes with slightly different options and layouts.

Role/Responsibility

UI Designer

Users

Authors

Scope

  • Merge the S1000D and Horizon Inboxes to minimize the use of code
  • Add new columns to the data display
  • Add the ability to assign documents

Constraints

The java application itself

Results

A single ‘one stop’ Inbox for users to access their documents in AuthorPro, creating a more consistent experience.

There is also less code now for the developers to manage as there is only one Inbox dialog.

Mockups

Starting the mockups, I used the Manager Inbox as a baseline for the layout since it’s something they’re familiar with.

I took the existing filters from the Inbox and added some useful new ones. In the focus group session I previously completed, I received information on how they filter down to documents they need in this dialog.

After discussing with the developers, pagination was added in order to reduce the dialog’s initial load time. If we tried to load a lot of documents into the dialog at once, the dialog would load in about 40 - 60 seconds, which rose as more documents were included. By only loading 25 max a time, we could reduce it to 5 - 10 seconds.

Finally, I added the new columns to the table (QA Status and Step).

While under development, a problem comes in. The table in the Inbox cannot have both pagination and sort the entire set of results.

I talk with the developer over options. Why can’t we sort an entire table by headers? What’s available to me that I can use? The answer to the first is event signals. The table headers don’t send event signals. They only sort the widget itself. There’s a few answers to the second. Nothing I like. This will be a “make the best of a bad situation” deal.

I end up on a combination of a column drop down and sorting direction button. The column will set the column to sort the entire list by, and the button will display the current direction of sort. Clicking the button will change the sort indicator on the button and sort the table by the selected column.
